# zoom-platform

多校区教育培训机构管理平台。

项目计划采用 Java 17、Spring Boot、Vue 3、MySQL 和 Redis 构建。首个里程碑将完成登录认证、角色权限、用户管理、校区管理和响应式工作台基础骨架。

## Planned structure

```text
zoom-platform/
|- server/   # Spring Boot backend
|- web/      # Vue 3 frontend
`- deploy/   # Docker Compose and Nginx configuration
```

详细的开发和运行说明将在工程初始化后补充。
