# 用户目录模块

## 当前边界

本模块提供用户查询、详情、创建、资料维护、角色与校区分配，以及账户启停。密码重置尚未开放，将在短期凭据与强制改密策略确定后单独接入。

## 接口

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/api/v1/users` | `user.read` | 分页查询用户 |
| `GET` | `/api/v1/users/options` | `user.read` | 查询状态、可分配校区和操作者可授予角色 |
| `GET` | `/api/v1/users/{id}` | `user.read` | 查询用户档案、角色、校区和安全状态 |
| `POST` | `/api/v1/users` | `user.manage` | 创建用户并设置初始密码、角色与校区 |
| `PUT` | `/api/v1/users/{id}` | `user.manage` | 更新资料、角色与校区，要求 `version` |
| `PATCH` | `/api/v1/users/{id}/status` | `user.manage` | 启用或停用用户，要求 `version` |

列表参数：

| 参数 | 默认值 | 约束 | 说明 |
| --- | --- | --- | --- |
| `keyword` | 空 | 可选 | 匹配姓名、用户名、邮箱或电话 |
| `status` | 空 | `PENDING`、`ACTIVE`、`LOCKED`、`DISABLED` | 按账号状态筛选 |
| `campusId` | 空 | 当前数据范围内校区 ID | 按校区关联筛选 |
| `page` | `1` | `1` 至 `1000000` | 页码 |
| `pageSize` | `20` | `1` 至 `100` | 每页记录数 |

## 数据范围

- `ALL`：查看全部用户、角色和校区关联。
- `ASSIGNED_CAMPUSES`：只查看与操作者共享至少一个校区的用户。
- `SELF`：只查看本人。
- 用户详情不存在或不在当前范围时返回 `404 USER_NOT_FOUND`。
- 分配校区范围的详情只返回操作者可访问的校区关联。即使目标用户同时属于其他校区，也不会暴露其他校区的 ID、编码或名称。
- 使用无权访问的 `campusId` 筛选时返回空页，不能通过共享用户关系推断其他校区成员。

权限点和数据范围同时生效。只有 `user.read` 才能访问用户目录，数据范围再决定可见记录与关联字段。

## 写操作约束

- `ALL` 管理员可以管理全局范围内不高于自身级别的用户和角色。
- `ASSIGNED_CAMPUSES` 管理员只能管理全部校区关联都在自身范围内的用户，不能覆盖目标用户的隐藏校区关联。
- 操作者不能授予排序级别高于自身的角色；非 `ALL` 操作者不能授予 `ALL` 数据范围角色。
- `ASSIGNED_CAMPUSES` 角色必须至少关联一个当前启用的可访问校区；主校区必须属于已分配校区。
- 用户名、邮箱和电话保持唯一，资料与状态更新使用 `version` 乐观锁。
- 不能通过用户管理接口更改自己的账户状态；手工状态操作仅支持 `ACTIVE` 与 `DISABLED`。
- 不能通过管理接口修改自己的资料、角色和校区，个人资料后续由独立的“我的账户”流程维护。
- 创建、资料与分配更新、状态变更均写入 `sys_operation_audit`。

## 返回内容

列表包含用户基本身份、状态、角色、可见校区、最近登录时间和版本。详情额外包含语言、时区、失败登录次数、锁定时间、密码更新时间与创建时间，不返回密码摘要、刷新令牌或其他认证秘密。

## 前端交互

- `/users` 路由要求 `user.read`，导航根据权限显示。
- 桌面端使用用户表格，移动端使用紧凑卡片。
- 可组合姓名/账号关键字、状态和校区筛选。
- 用户详情弹窗明确展示角色数据范围、主校区和安全状态。
- 拥有 `user.manage` 的操作者可以使用新建/编辑表单和独立的启停确认操作。
- 角色使用复选控件，校区使用复选控件并为已选校区提供主校区单选。

## 验证

只读目录已有的后端与前端测试保持不变。根据当前开发安排，本轮写操作仅执行后端跳过测试编译和前端生产构建；写操作集成测试、MySQL Testcontainers 与浏览器回归在用户与权限功能全部完成后统一执行。
